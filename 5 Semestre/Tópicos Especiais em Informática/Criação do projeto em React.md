### ***Criando o primeiro projeto
* Abra o CMD, entre na pasta onde deseja criar o projeto (utilizando cd).
* Digite "npx create-expo-app [nome do projeto] -t".
* 3 Blank (TypeScript)
* (Expo go) SDK 54
* Para executar o projeto, digite "npm run start", sempre dentro da pasta do projeto.
