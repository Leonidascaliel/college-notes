As chamadas linguagens universais, como **JSON** e **XML**, não são linguagens de programação no sentido tradicional, mas sim **linguagens de marcação ou de estruturação de dados** utilizadas para representar e transportar informações entre diferentes sistemas, plataformas e linguagens de programação. Elas são consideradas universais porque podem ser interpretadas por praticamente qualquer linguagem ou tecnologia existente.

#### JSON (JavaScript Object Notation)

O **JSON** é um formato leve de troca de dados, baseado na estrutura de objetos do **JavaScript**. Ele é amplamente utilizado em **APIs, aplicações web e comunicação entre sistemas**, pois possui uma sintaxe simples e é fácil de ler tanto para humanos quanto para máquinas. Atualmente, é o padrão mais utilizado para transmissão de dados em aplicações modernas, especialmente em **APIs REST**.

Exemplo:

`{`  
  `"nome": "Leonidas",`  
  `"idade": 25,`  
  `"profissao": "Data Analyst"`  
`}`

#### XML (extensible Markup Language)

O **XML** é uma linguagem de marcação criada para armazenar e transportar dados de forma estruturada. Ele utiliza **tags personalizadas** para organizar as informações e foi amplamente utilizado em sistemas corporativos, integrações de software e serviços web. Embora ainda seja usado em diversas aplicações, atualmente muitas soluções têm migrado para JSON devido à sua simplicidade.

Exemplo:

`<pessoa>`  
  `<nome>Leonidas</nome>`  
  `<idade>25</idade>`  
  `<profissao>Data Analyst</profissao>`  
`</pessoa>`

#### Características das Linguagens Universais

- Independentes de linguagem de programação
    
- Utilizadas para **troca de dados entre sistemas**
    
- Estrutura padronizada e facilmente interpretável
    
- Amplamente utilizadas em **APIs, bancos de dados, configurações de sistemas e integração de softwares**
    

Esses formatos são fundamentais no desenvolvimento moderno, pois permitem que aplicações desenvolvidas em diferentes tecnologias consigam **se comunicar e compartilhar informações de forma padronizada**.
