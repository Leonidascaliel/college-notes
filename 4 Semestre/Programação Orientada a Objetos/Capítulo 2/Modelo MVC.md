### O que é um modelo MVC?
A sigla é representada por:
	M = Model (Diagrama de Classe)
	V = View (I.U (GCI))
	C = Control (SGBD, SQL)

Exemplo: 
	Para criar uma estrutura "src" dentro do NetBeans, basta selecionar "Pacote" durante a criação de uma classe. Em seguida, coloque os nomes das pastas separando por ".".
