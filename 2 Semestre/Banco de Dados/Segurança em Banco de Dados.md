### Pontos essenciais para proteger informações e dados confidenciais de ataques e falhas no sistema
• Controle de Redundância (Impede duplicação de Registro);
• Controle de Concorrência (Evitando conflitos de informações e garantindo
dados corretos);
• Restrições de integridade (Impedindo a alterações indevidas);
• Apenas pessoal autorizado.

Para evitar esses problemas, medidas de controle de acesso e monitoramento
devem ser implementadas.

O administrador do banco de dados (DBA) desempenha um papel importante no
processo, criando e gerenciando contas de acesso ao sistema, definindo
permissões e revogando também.

Umas das ameaças mais recorrentes é a injeção do SQL. Que permite a execução
de comandos maliciosos.
Para evitar esse risco, é fundamental avaliar corretamente as entradas de usuários.

### Restrição de Acesso
• É utilizado os Views para limitar a exibição de informações a determinados
usuários.
Controle de Fluxo
• Impede que informações sigilosas sejam transferidas para locais não
autorizados.

A criptografia é a maneira mais segura e eficaz de proteger os dados, transformam
as informações em códigos indecifráveis para pessoas não autorizadas.

Prática fundamental, Backups Periódicos.
A proteção ao BD exige atualizações constantes para acompanhar novas ameaças.
A adoção de boas práticas é fundamental para manter as regras, implementando
testes e treinamentos e aplicação de medidas preventivas.
